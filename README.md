# EduMentor AI 🎓

EduMentor AI is a smart, AI-powered study assistant built with Streamlit and OpenAI GPT-4.

## 🔧 Features

- ✅ Topic Explainer
- ✅ Quiz Generator (3 MCQs)
- ✅ Study Plan Creator (day-wise plan)
- ✅ Saves recent history using SQLite

## 💻 Setup Instructions

1. Clone or download this project.
2. Install requirements:

```bash
pip install -r requirements.txt
```

3. Run the app:

```bash
streamlit run app.py
```

4. Enter your OpenAI API Key in the sidebar.

## 🧠 Built With

- Python
- Streamlit
- OpenAI GPT-4
- SQLite (for history)

Enjoy learning with EduMentor AI!
